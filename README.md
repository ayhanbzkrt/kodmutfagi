## Türkçe

### Proje Hakkında

**AI’Han Kod Mutfağı**, HTML, CSS, JavaScript ve Python kodlarının doğrudan web tarayıcısında yazılmasını, düzenlenmesini, çalıştırılmasını ve sonuçlarının anında görüntülenmesini sağlayan etkileşimli bir kod geliştirme ve öğrenme ortamıdır.

CodePen benzeri canlı kod düzenleme deneyimini, Python çalıştırma ve Türkçe programlama eğitimi özellikleriyle bir araya getirir.

Yalnızca kod yazmayı değil, kodun nasıl çalıştığını anlamayı, hataları analiz etmeyi, algoritmaları incelemeyi ve uygulamalı programlama becerileri geliştirmeyi amaçlar.

Öğrenciler, eğitimciler, yazılımcılar ve programlamaya ilgi duyan herkes için tasarlanmıştır.

### Temel Özellikler

**HTML, CSS ve JavaScript Editörü**
- HTML, CSS ve JavaScript kodlarını ayrı alanlarda yazma ve düzenleme
- Tam HTML belgelerini doğrudan yapıştırıp çalıştırma
- Canlı web sayfası önizlemesi
- Modern CSS özellikleri ve duyarlı tasarım desteği
- JavaScript ve ES Modules çalıştırma
- TypeScript, JSX ve TSX için tarayıcı tabanlı dönüştürme
- React ve Vue gibi kütüphanelerle örnek çalışmalar
- Tailwind CSS ile hızlı tasarım önizlemesi
- JavaScript konsolu ve hata mesajları

**Python Çalışma Ortamı**
- Pyodide ve WebAssembly ile tarayıcıda Python çalıştırma
- Web Worker aracılığıyla arayüzden bağımsız kod yürütme
- Python kodlarını yapıştırma, düzenleme ve çalıştırma
- `print()` çıktıları ve kullanıcı girdileri
- Python hatalarının Türkçe açıklanması
- Otomatik paket yükleme ve uyumluluk denetimi
- Matplotlib grafiklerinin görüntülenmesi
- Uzun süren işlemleri durdurma ve Python motorunu yeniden başlatma

**Python Kütüphaneleri**

Uygulama, Pyodide ile uyumlu Python paketlerinin kullanılmasını destekler.

Öne çıkan kütüphaneler:

- NumPy — Sayısal hesaplamalar
- pandas — Veri analizi ve veri işleme
- Matplotlib — Grafik ve veri görselleştirme
- SciPy — Bilimsel hesaplama

- SymPy — Sembolik matematik
- Pillow — Görüntü işleme
- Beautiful Soup — HTML ve veri ayrıştırma
- NetworkX — Ağ ve çizge analizi

Temel paketler otomatik olarak hazırlanır. Kod içerisindeki `import` ifadeleri üzerinden diğer uyumlu paketler de yüklenmeye çalışılır.

- Adımlar arasında ileri ve geri gezinme
- Kodun üreteceği sonucu tahmin etme etkinlikleri
- Etkileşimli Python alıştırmaları

- Hataların nedenlerini örneklerle açıklama

## English

### About the Project

**AI’Han Kod Mutfağı (AI’Han Code Kitchen)** is an interactive browser-based coding and learning environment that enables users to write, edit, execute, and preview HTML, CSS, JavaScript, and Python code.

It combines a CodePen-like live editing experience with browser-based Python execution, interactive programming education, and Turkish-language error explanations.

The platform is designed not only to run code but also to help users understand how programs work, analyze errors, explore algorithms, and improve their practical programming skills.

It is intended for students, educators, developers, and anyone interested in learning or experimenting with programming.

### Key Features

**HTML, CSS, and JavaScript Editor**
- Separate editing environments for HTML, CSS, and JavaScript
- Support for pasting and running complete HTML documents
- Live website preview
- Modern CSS and responsive design support
- JavaScript and ES Modules execution
- Browser-based TypeScript, JSX, and TSX transformation
- Examples using libraries such as React and Vue
- Tailwind CSS design previews
- JavaScript console and error reporting

**Python Environment**
- Browser-based Python powered by Pyodide and WebAssembly
- Web Worker execution to keep the interface responsive
- Python code editing and execution
- Standard output and user input handling
- Turkish explanations of Python errors
- Automatic loading of compatible Python packages
- Matplotlib chart rendering
- Execution cancellation and Python runtime recovery

**Python Libraries**

The application supports Python packages compatible with Pyodide, including:

- NumPy — Numerical computing
- pandas — Data analysis
- Matplotlib — Data visualization
- SciPy — Scientific computing
- scikit-learn — Machine learning
- SymPy — Symbolic mathematics
- Pillow — Image processing
- Beautiful Soup — HTML parsing
- NetworkX — Network analysis

Core packages are prepared automatically. Additional compatible dependencies can be detected from Python `import` statements and loaded when supported.

**Interactive Python Tutor**
- Step-by-step code execution analysis
- Turkish explanations of executed lines
- Variable value tracking
- Loop, condition, and function inspection
- Forward and backward execution navigation
- Output prediction exercises
- Interactive Python learning activities

**Intelligent Error Guide**
- Syntax error detection
- Problematic line highlighting
- Turkish explanations of Python error messages
- Detection of common punctuation and indentation mistakes
- Contextual explanations and correction suggestions
- User-approved application of suggested fixes

### Additional Capabilities

- Syntax highlighting and line numbers
- Ready-to-use coding examples
- Responsive desktop, tablet, and mobile interface
- HTML and Python file export
- Project saving and reopening
- Execution status indicators
- Package loading progress
- Clear error and recovery messages
- Accessible, light-themed interface

### Getting Started

1. Open `AIHan_Kod_Mutfagi_6.html` in a modern browser or visit the hosted application.
2. Choose the HTML, CSS, JavaScript, or Python workspace.
3. Write your code or paste an existing example.
4. Click **Run** to execute it.
5. Inspect the output in the preview or console.
6. Use the Python learning mode to explore execution steps.
7. Modify, improve, and export your project.

**No local development environment is required.** You do not need to install Python, Node.js, or a separate application server.

### Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Editor and application logic |
| Pyodide | Browser-based Python execution |
| WebAssembly | Python runtime |
| Web Workers | Isolated execution workflow |
| Babel | JSX and TSX transformation |
| TypeScript | TypeScript compilation |
| iframe | Isolated web preview |

### Technical Limitations

- Initial loading of the Python runtime and some libraries requires an internet connection.
- Not every package from the desktop Python ecosystem is supported by Pyodide.
- Libraries requiring operating-system access or unsupported native dependencies may not work in browsers.
- Some JavaScript frameworks require additional build tools or backend infrastructure.
- Browser-based Tailwind CSS integration is intended for development and preview purposes.
- Hosting the application on a static HTTPS service such as GitHub Pages is recommended.
- Automatic correction of every user-written programming error cannot be guaranteed.

### Project Vision

AI’Han Kod Mutfağı aims to make programming more accessible, interactive, and understandable.

By combining live code execution, error analysis, visual learning tools, and practical experimentation, the project encourages users to learn through exploration rather than passive instruction.

Its long-term goal is to provide a comprehensive browser-based coding environment that supports both software development and programming education.
